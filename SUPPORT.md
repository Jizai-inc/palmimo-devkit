# Support

- **Questions and ideas** — open a
  [GitHub Discussion](https://github.com/Jizai-inc/palmimo-devkit/discussions).
  "How do I…", setup help, and showing off what you built all belong there.
- **Bugs** — open an
  [issue](https://github.com/Jizai-inc/palmimo-devkit/issues/new/choose) with
  the bug report template. The hardware fields in the template are what we
  need to reproduce motion problems.
- **Security issues** — do not open a public issue; see
  [SECURITY.md](SECURITY.md) for the private reporting channel.
- **DevKit owners** — warranty, repairs, and paid support (custom development,
  training) go through the [contact form on palmimo.dev](https://palmimo.dev/en/contact),
  not through GitHub.

Support is best-effort: this project is maintained by a small team alongside
hardware development, so there is no guaranteed response time.
