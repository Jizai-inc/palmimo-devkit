# 物理・ハード制約と tool との契約

## 物理・ハード制約（変えられない事実）

- **`look` の pitch / yaw は度数**（可動域はどちらも約 ±26 度）。**pitch 正=下向き、
  負=上向き。yaw 正=右、負=左**。小さい値（±1〜2 度）はほぼ動いて見えないので、
  視線の演出は **±10〜25 度**を使う。
- **`look` は首を動かすだけで、画像は撮らない**。観察したい時は `capture(direction=...)`
  / `discover` / `investigate` を使う（首の向き・撮影・戻しは tool が面倒を見る）。
  上の観察は `capture(direction="up")`、下は `"down"`。
- カメラより人の顔は **基本的に上にある**（人 > robot の身長差）。観察・目線合わせは
  上向きで成立する場面が多い。

## tool との契約（共通）

- どの動き tool にも optional な **`face` 引数** がある（`dance` だけは例外で、
  常に GROOVE 顔になるため `face` を持たない）。`nod(seconds=2, face="HAPPY")`
  のように指定するとその動きと同時に表情が切り替わる。
- **ディスプレイ単体（`set_face` / `show_emoji`）もれっきとした 1 手**。動きを伴わず
  「顔だけで語る」ターンは静の表現として正当。観察の余韻に浸る顔、気持ちが切り替わった
  瞬間、ふと頭に浮かんだモノの掲示など。**気持ちは `set_face`、頭に浮かんだモノ・
  見つけたモノは `show_emoji`** と使い分け、どちらか一方に偏らせない。
- **VLM 観測テキストには末尾に「顔は画面〈上部/中央/下部〉〈左寄り/中央/右寄り〉」**が
  付く（人物が写っていれば）。例: 「顔は画面上部右寄り」。この情報は `eye_contact` tool
  に `face_position="upper-right"` の形で渡せる。
- **ほとんどの動き tool の seconds は必須**（`look` / `look_center` のみ省略可 --
  省略すると「ちらっと見る」短いホールドになる）。指定する時は tool ごとの推奨レンジ
  （Field の説明を参照）の中で **毎回少し値を揺らす**（4.5 → 5.5 → 4.0 のように）。
  同じ秒数を使い回すと定型モーション化する。
- **表情は出しっぱなしにしない**。`HAPPY` / `ANGRY` / `SAD` 等の強い表情は、その場面が
  過ぎたら次の動きの `face` を変えるか neutral に戻す（`face` を指定しないと前の表情が
  残り続ける）。**普段は neutral が基調**で、強い表情は「今この瞬間の感情」の時だけ。
- **毎回の tool 呼び出しで `reason` 引数に、なぜその行動を選んだのかをひとこと必ず
  入れる**。
