Palmimo DevKit は AI エージェントに身体を与えます。自分のコードで動かせる、カスタマイズ可能な汎用 AI ロボットです。組み立てとテストを済ませた状態でお届けします。Palmimo は 6 本脚のデスクトップコンパニオンロボットです。脚の 18 個のサーボがトライポッド歩容で歩かせ、サーボで動く首が丸いフェイスディスプレイの向きを変え、小さな表情エンジンが表情を作ります。カメラ、マイク、スピーカーも備え、SDK はどれも同じ方法でロボットに提供します。そのため、下のロボットは指示に応じて表情を変え、見えているものを表示し、録音します。

1 つの**モーションエンジン**（I/O を含まない、歩容と逆運動学の純粋な計算）が、交換可能なフロントエンドである `palmimo_sdk` Python API とサンプルのエージェントアプリを通じてロボットを動かします。どのモーションもサーボに届く前に、ハードウェアを接続しないドライランで計算できます。
